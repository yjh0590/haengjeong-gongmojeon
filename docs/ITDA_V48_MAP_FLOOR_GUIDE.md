# ITDA v4.8 · 송도 타임스페이스 지도·층별 탐색 고도화

## 기준

2026-10-29 사용자가 업로드한 `haengjeong-gongmojeon-main (1).zip`의 **v4.5**를 수정했습니다. v4.6·v4.7의 별도 첫 화면/상단 메뉴 시안은 적용하지 않았습니다. 소비자·점주·관리자 서브도메인(`customer.itda.ink`, `owner.itda.ink`, `editor.itda.ink`)과 Supabase 구조는 그대로 유지합니다.

## 새 기능

- **소비자용 `customer.itda.ink`**: 기존 지도에서 건물별 점포 필터와 층별 점포 수를 확인할 수 있습니다. 점포 카드를 누르면 연결된 촬영 지점과 거리 사진을 볼 수 있습니다.
- **촬영 지점 연결 안내**: 점포 카드에서 **현재 촬영 지점에서 찾아보기**를 누르면 미리 입력된 `nodes.connections`를 따라 최단 **촬영 지점 수**로 이동하는 안내가 표시됩니다. 사용자는 **다음 촬영 지점 보기** 버튼으로 한 지점씩 이동할 수 있습니다. 지점이 연결되어 있지 않으면 안내를 임의로 만들지 않고 오류 이유를 안내합니다.
- **층별 위치 설명**: 2·3층 점포는 외부에서 보이는 건물·촬영 지점과만 연결하며, 실내 통로/엘리베이터를 확인했다고 주장하지 않습니다.
- **관리자 `editor.itda.ink/map-editor`**: 사진 없는 지점, 연결이 끊긴 촬영 지점, 점포가 어떤 지점과도 연결되지 않은 경우를 점검합니다. 지도에서 층별 점포 마커만 미리 볼 수 있습니다.
- **현장 촬영 체크리스트**: 관리자가 **촬영 계획표 CSV 내려받기** 버튼을 누르면 지점×방향별 촬영 목록과 사진 등록 현황이 한국어 CSV로 저장됩니다. 이 자료로 팀원에게 촬영 업무를 분배할 수 있습니다.
- **지도 좌표 보정**: 지도 편집기에서 반응형 SVG의 좌표 변환(`getScreenCTM`)을 사용해 브라우저 크기에 따른 좌표 오차를 줄였습니다.

## 현장에서 진행할 실제 작업

1. 관리자 지도 편집기에서 사용 권한이 확인된 지도를 등록하고 전체 상권 경계 및 보행 통로를 지정합니다.
2. 1층/2층/3층 구분, 각 건물·동·호수와 점포 연결 정보가 사실인지 확인합니다. **건물별 필터의 건물명은 관리자 점포 목록에서 가져옵니다.**
3. 실제 촬영 가능 지점들을 추가합니다. 연결할 때 **사람이 이동할 수 있는 지점**끼리만 방향을 설정하고 반대 방향 링크도 필요하면 별도로 등록합니다.
4. `촬영 계획표 CSV 내려받기`로 지점별 사진 수집 목록을 만든 다음 실제 사진을 촬영합니다.
5. 사진은 `/street-editor`에서 등록하고, 가게 영역을 표시합니다. 등록 내용은 **해당 브라우저의 임시 데이터**이므로 주기적으로 백업합니다.
6. 관리자 `/catalog`에서 사진 파일을 제외한 점포·지도·촬영 지점 데이터를 검토해 Supabase에 게시할 수 있습니다. `customer.itda.ink` 등 다른 서브도메인에서 공유되는 것은 서버에 **게시한 데이터에 한정**됩니다.

## 현재 제공되지 않는 기능

- 거리의 실제 미터·시간 계산, 지점별 GPS/보행자 내비게이션, 무장애 길찾기
- 360도 파노라마 탐색 (현재 일반 촬영 사진 방향 전환)
- 관리자 브라우저에 임시 저장한 지도 배경 이미지/거리 사진의 다른 서브도메인 자동 공유
- 공공데이터 API에 의한 점포 변동 자동 동기화 및 실제 AI 점포 인식

경계·가게 마커의 초기 좌표 및 데모 점포 6개는 **시연용**입니다. 이전에 전달한 네이버 지도 캡처는 권한 검증 전 프로젝트에 포함하지 않았습니다.

## 테스트

```bash
npm ci
npm run test:route
npm run dev
npm run build
```

테스트 항목: 건물 필터 → 층 선택 → 점포 선택 → 촬영 지점 안내 → 다음 지점 이동 → 지도 편집에서 촬영 누락 확인 → CSV 저장. 이 버전은 필요한 패키지 설치가 불가능한 제작 환경이라 **Vite 전체 빌드/브라우저 확인은 별도 환경에서 수행**해야 합니다. TypeScript/TSX 구문·CSS 문법·촬영 연결 계산은 개별 검증했습니다.
