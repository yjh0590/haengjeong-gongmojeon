# ITDA v4.6 — 화면 디자인 개편 안내

## 적용 화면
- `itda.ink` : 사진 배경형 메인 히어로 + 3개 핵심 기능 소개 + 소비자/점주 바로가기
- `customer.itda.ink` : 탐색 중심 지도 프리뷰와 바로가기, 기존 실제 지도·층별 필터·촬영 사진·점포 검색·즐겨찾기 유지
- `owner.itda.ink` : 오렌지 프로모션 배너와 기능 카드 추가, 기존 로그인·공통 점포 데이터·홍보안 작성/제출 유지
- `editor.itda.ink` : 진녹색 사이드바와 실제 로컬 작업 통계 카드 추가, 기존 관리자 인증·점포 관리·지도·사진·홍보 승인·백업 유지

## 사진 교체
`public/brand/` 안의 다음 **임시 콘셉트 배경**을 같은 파일명으로 교체할 수 있습니다.
- `bridge.webp`: 메인 상단 인천 대표 이미지 (권장 1600×700 이상, 가로 사진)
- `songdo.webp`: 소비자용/서비스 카드 송도 상권 이미지 (권장 1200×600 이상)
- `sunset.webp`: 점주용 홍보 상단 사진 (권장 1600×700 이상)
- `forest.webp`: 관리자 콘셉트 예비 이미지 (현재 주요 화면에는 사용하지 않음)
현재 배경은 이전 콘셉트 이미지에서 가공한 **임시 시각 자료**로, 실제 촬영한 현장 사진 또는 장소·저작권 사용이 검증된 사진으로 교체하는 것을 권장합니다. 이미지 속 풍경은 실제 최신 상권 모습의 증거가 아닙니다.

## 구현 원칙
- UI만 변경하고 Supabase URL/키나 SQL을 변경하지 않았습니다.
- 소비자 지도·가게 좌표·층·거리 사진은 이전 데이터를 그대로 읽습니다.
- 지도 프리뷰의 핀을 누르면 실제 등록된 촬영 지점으로 이동합니다. 미리보기 위치는 **시각적 구성을 위한 예시**입니다.
- 관리자 작업 통계는 DB 통계가 아닌 브라우저 초안의 점포·사진·촬영 지점·외곽선 수입니다.
- 신규 타임스페이스 촬영 사진, 점포 정보, 점주 홍보안의 내용은 기존 편집기에서 추가 가능합니다.
- 출처 표기 및 사진 이용권한 확인은 공개 전 필요합니다.
