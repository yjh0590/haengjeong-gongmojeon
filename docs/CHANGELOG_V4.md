# ITDA v4 변경 이력 (v3 대비)

| 구분 | 변경 사항 | 서비스 적용 상태 |
| --- | --- | --- |
| 관리자 | `/catalog` 점포 추가·수정·삭제 및 층·호수 편집 | 구현 |
| 관리자 | 점포 JSON 가져오기·내보내기 | 구현 |
| 관리자 | `/map-editor` 점포 목록을 새 초안과 연결 | 구현 |
| 관리자 | `/street-editor` 가게 영역 선택을 새 초안과 연결 | 구현 |
| 관리자 | 사진 포함 전체 백업에 점포 목록 포함 (v1 백업 가져오기 호환) | 구현 |
| 관리자 | Supabase Auth 로그인·관리자 권한 확인·게시 | 코드 구현, 서버 설정 필요 |
| 서버 | 점포·지도·촬영 지점·윤곽선 단일 게시본 | SQL 제공, 서버 설정 필요 |
| 소비자 | 서버 게시본이 있으면 공통 점포 및 지도 사용 | 코드 구현, 서버 설정 필요 |
| 소비자 | 게시본/시연 정보 상태 구분, 미연결 가게 임의 길찾기 방지 | 구현 |
| 사진 | 브라우저 임시 사진을 실제 서버에 올리기 | **미구현** |
| 점주 | 점주 홍보물이 소비자 페이지에 자동 게시 | **미구현** |
| 자동화 | 공공데이터 API 신규·폐업 자동 감지 | **미구현** |

## 현재 버전의 핵심 개념

`관리자 초안` → `지도·점포 위치 연결` → `관리자 로그인·승인` → `Supabase 저장` → `소비자용 새로고침 시 공개본 읽기`

서버 설정이 없으면 기존처럼 로컬에서 초안과 동일 주소 미리보기만 제공하며, 게시 버튼은 비활성화됩니다.
