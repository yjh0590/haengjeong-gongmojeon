# ITDA v5.0 · 타임스페이스 전체 상권 안내도 스타일 업데이트

## 변경 내용
- 소비자용 `customer.itda.ink`의 「타임스페이스 전체 상권 안내」 패널 배경을 송도 타임스페이스 구역을 참고해 새로 그린 SVG 개념도로 변경했습니다.
- 반응형 벡터 지도: 부드러운 블루그레이 격자, 흰색 통행 공간, 연녹색 상가 블록, 인근 녹지/수변 표시.
- 기존 촬영 지점·점포 버튼은 React 데이터 위에서 동작하므로 클릭, 층별 필터, 안내 경로, 즐겨찾기, 사진 선택 기능을 유지합니다.
- Supabase에 이미 등록한 지도 배경 이미지가 있으면 소비자가 `간편 안내도 / 관리자 등록 지도`로 전환할 수 있습니다.
- 관리자 지도 편집기는 커스텀 지도 이미지가 없을 때 같은 개념도를 사용합니다. 커스텀 지도 이미지가 있으면 등록 이미지를 계속 사용해 편집 좌표를 보호합니다.
- 지도 디자인 이미지: `public/brand/timespace-schematic.svg`. 이 파일을 변경하면 기본 배경이 바뀝니다.

## 매우 중요 — 지도의 사실성·데이터
- **지도는 참고 스크린샷을 바탕으로 단순화한 디자인 시안**이며 공인 지적도나 검증된 평면도가 아닙니다.
- `A구역`, `B구역`, `C구역`, `D구역`은 **임시 구역 표기**입니다. 실제 동·호수, 통로, 출입구, 건물 외곽선 등은 아직 검증되지 않았습니다.
- 기존 등록된 좌표와 새 개념도의 건물 배치는 일치하지 않을 수 있습니다. 4개 촬영 지점과 각 점포는 **관리자 지도 편집기에서 실제 사진 및 현장 측량에 맞춰 재배치**해야 합니다.
- 대외 공개 전 실제 건물 배치, 상가 주소, 층별 출입구와 길을 현장 조사해야 합니다.
- 외부 지도 캡처를 SVG에 그대로 넣지 않았으며, 이미지는 새로 제작한 도식입니다.

## 적용 방법
1. ZIP을 압축 해제합니다.
2. GitHub Desktop의 기존 `haengjeong-gongmojeon` 저장소에 소스 파일을 덮어쓰고 변경된 파일을 Commit → Push 합니다.
3. Vercel 빌드 완료 후 `https://customer.itda.ink`에서 안내도를 확인합니다.
4. 커스텀 지도가 있을 경우 `간편 안내도 / 관리자 등록 지도` 버튼으로 비교할 수 있습니다.
5. 관리자 지도 편집기 `https://editor.itda.ink/map-editor`에서 지점·가게 좌표와 실측 지도를 확인합니다.

## 서버 / 환경 변수
- **새로운 Supabase SQL은 필요 없습니다**. v4.9의 Storage 설정을 유지합니다.
- 기존 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`는 변경하지 않습니다.

## 검증
- TypeScript/TSX 코드 문법, CSS 파싱, SVG XML, ZIP 무결성을 확인했습니다.
- 이 실행 환경에 Vite 패키지 캐시가 없어 `npm ci --offline`이 실패했고, **실제 프로덕션 빌드·브라우저 검증은 수행하지 못했습니다**. Vercel Deployments에서 빌드 결과를 확인하세요.
