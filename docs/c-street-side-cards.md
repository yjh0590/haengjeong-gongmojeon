# 거리 사진의 왼쪽·오른쪽 가게 카드

- 거리 입구에서 **거리 안으로 들어가기**를 누르면 C동 거리 사진이 열립니다.
- 사진의 **왼쪽 가게 보기 / 오른쪽 가게 보기**를 누르면 거리 사진이 있던 같은 카드 영역이 `STORES IN VIEW`로 전환되어 해당 면의 카드만 표시합니다. 카드 위에서 면을 바꾸거나 **거리 사진으로 돌아가기**를 누를 수 있습니다.
- 정면을 기준으로 왼쪽에는 대빵 오락실 → 오봉집 → 세븐일레븐이 연결됩니다. 뒤를 보는 동안에는 같은 면이 오른쪽입니다. 반대편에 임의의 매장을 넣지 않습니다.
- 사진은 앞·뒤 촬영 원본을 유지합니다. 면 선택은 가게 카드의 선택이며, 촬영되지 않은 측면 사진이나 이동 경로를 만들지 않습니다.
- 카드는 거리 사진과 동시에 아래에 표시하지 않고, 같은 카드 안에서 가로로 3개씩 표시합니다. 모바일에서도 세로로 쌓지 않고 가로로 밀어 볼 수 있습니다. 사진은 카드당 한 번만 표시하며 누르면 상세 정보가 열립니다.
- 가게가 4곳 이상이면 기존 이전·다음 버튼으로 3곳씩 넘깁니다. 지점·방향·면이 바뀌면 첫 카드 묶음부터 표시합니다.

관리자의 기존 방향별 카드 연결(`viewStores`)을 사용합니다. C동 예시는 `left`에 3곳을 연결하고 `forward`, `back`, `right`는 빈 목록으로 둡니다. 방향은 정면 기준이며 손님 화면에서 현재 보는 방향에 맞춰 좌우를 계산합니다. 사진이 없는 방향에도 카드 연결은 가능합니다. 기존 게시 자료는 자동으로 덮어쓰지 않으므로 이미 게시한 C동 자료는 관리자에서 왼쪽 연결을 지정한 뒤 전체 게시해야 합니다.

검사: `node scripts/test-c-street-tour.cjs`, `npm run build`, `npm run lint` 통과. lint 기존 경고 14개. 브라우저 1440·1024·768·390·320px에서 입구 진입, 앞·뒤에 따른 좌우 전환, 가로 카드 3개, 중복 이미지 제거, 사진/카드 상호 전환과 돌아가기 초점 복원, 상세 닫은 뒤 선택 유지, 가로 넘침 방지를 확인했습니다.

## 동·층별 가게 사진 (거리뷰 안)

- 거리 사진 아래 **A·B·C·D동 가게 둘러보기**를 누르면 같은 카드 영역에서 간판 사진 디렉터리(`StorefrontDirectory embedded`)가 열립니다. 동 탭 → 층 → 검색 순으로 거르고 3개씩 넘깁니다. 모바일은 가로로 밀어 봅니다.
- 좌우 버튼이 있는 지점에서는 **사진 속 가게 / 동·층별 가게 사진** 탭으로 전환합니다. 좌우 버튼이 없는 지점에서는 탭을 숨깁니다.
- 동·층별 목록은 주소·간판 대조 자료일 뿐 사진 속 좌우 위치가 아닙니다. 2층 이상 가게를 1층 거리의 가게처럼 표시하지 않습니다.
- 컴포즈커피(C동 118호, 공개 주소 기록)는 세븐일레븐(119호)과 호수가 인접하지만, 앞·뒤 거리 사진과 세븐일레븐 외관 사진에서 간판이 확인되지 않아 왼쪽 면 카드에 추가하지 않았습니다. 현장 사진으로 위치가 확인되면 관리자에서 `viewStores.left`에 연결합니다.
