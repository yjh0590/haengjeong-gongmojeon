# 거리 사진의 왼쪽·오른쪽 가게 카드

- 거리 입구에서 **거리 안으로 들어가기**를 누르면 C동 거리 사진이 열립니다.
- 사진의 **왼쪽 가게 보기 / 오른쪽 가게 보기**를 누르면 거리 사진이 있던 같은 카드 영역이 `STORES IN VIEW`로 전환되어 해당 면의 카드만 표시합니다. 카드 위에서 면을 바꾸거나 **거리 사진으로 돌아가기**를 누를 수 있습니다.
- 정면을 기준으로 왼쪽에는 대빵 오락실 → 오봉집 → 세븐일레븐이 연결됩니다. 뒤를 보는 동안에는 같은 면이 오른쪽입니다. 반대편에 임의의 매장을 넣지 않습니다.
- 사진은 앞·뒤 촬영 원본을 유지합니다. 면 선택은 가게 카드의 선택이며, 촬영되지 않은 측면 사진이나 이동 경로를 만들지 않습니다.
- 카드는 거리 사진과 동시에 아래에 표시하지 않고, 같은 카드 안에서 가로로 3개씩 표시합니다. 모바일에서도 세로로 쌓지 않고 가로로 밀어 볼 수 있습니다. 사진은 카드당 한 번만 표시하며 누르면 상세 정보가 열립니다.
- 가게가 4곳 이상이면 기존 이전·다음 버튼으로 3곳씩 넘깁니다. 지점·방향·면이 바뀌면 첫 카드 묶음부터 표시합니다.

관리자의 기존 방향별 카드 연결(`viewStores`)을 사용합니다. C동 예시는 `left`에 3곳을 연결하고 `forward`, `back`, `right`는 빈 목록으로 둡니다. 방향은 정면 기준이며 손님 화면에서 현재 보는 방향에 맞춰 좌우를 계산합니다. 사진이 없는 방향에도 카드 연결은 가능합니다. 기존 게시 자료는 자동으로 덮어쓰지 않으므로 이미 게시한 C동 자료는 관리자에서 왼쪽 연결을 지정한 뒤 전체 게시해야 합니다.

검사: `node scripts/test-c-street-tour.cjs`, `npm run build`, `npm run lint` 통과. lint 기존 경고 14개. 브라우저 1440·1024·768·390·320px에서 입구 진입, 앞·뒤에 따른 좌우 전환, 가로 카드 3개, 중복 이미지 제거, 사진/카드 상호 전환과 돌아가기 초점 복원, 상세 닫은 뒤 선택 유지, 가로 넘침 방지를 확인했습니다.

## 동·층별 가게 사진 (거리뷰 안)

- 거리 사진 아래 **A·B·C·D동 가게 둘러보기**를 누르면 같은 카드 영역에서 간판 사진 디렉터리(`StorefrontDirectory embedded`)가 열립니다. 동 탭 → 층 → 검색 순으로 거르고 3개씩 넘깁니다. 모바일은 가로로 밀어 봅니다.
- 좌우 버튼이 있는 지점에서는 **사진 속 가게 / 동·층별 가게 사진** 탭으로 전환합니다. 좌우 버튼이 없는 지점에서는 탭을 숨깁니다.
- 동·층별 목록은 주소·간판 대조 자료일 뿐 사진 속 좌우 위치가 아닙니다. 2층 이상 가게를 1층 거리의 가게처럼 표시하지 않습니다.
- 컴포즈커피(C동 118호, 공개 주소 기록)는 세븐일레븐(119호)과 호수가 인접하지만, 앞·뒤 거리 사진과 세븐일레븐 외관 사진에서 간판이 확인되지 않아 왼쪽 면 카드에 추가하지 않았습니다. 현장 사진으로 위치가 확인되면 관리자에서 `viewStores.left`에 연결합니다.

## 손님 화면 기본 거리 사진 (2026-11-06)

- 2026-11-02 게시본은 시험 자료(A 덮밥~F 편집숍 6곳, 촬영 지점 4곳, "외관" 시험 사진)입니다. 게시본에 C동 촬영 지점(`c-entry`)이 없으면 손님 화면(`/`)은 게시본 대신 `/street-demo`와 같은 C동 실제 자료(가게 3곳·촬영 지점 2곳·지도 위치)를 씁니다. 관리자가 C동 지점을 게시하면 게시본이 우선합니다.
- 관리자 `/catalog`의 **시험 자료를 C동 실제 자료로 교체**는 같은 내용을 초안으로 만듭니다(시험 가게·지점·사진 연결·외곽선 삭제, 지도 배경 유지). 전체 게시해야 서버 게시본이 바뀝니다.
- 배너 추천 카드는 가게의 실제 외관 사진이 있으면 그 사진을 씁니다.
- 간편 안내도의 C동 지점·가게 위치를 C구역과 맞은편 건물 사이 거리로 옮기고, 가게 핀과 겹치지 않도록 `C구역` 글자를 건물 가운데로 옮겼습니다. 위치는 개념도 기준이며 실측이 아닙니다.

## 가게 목록에 조사한 가게 반영 (2026-11-06)

- 간판 사진이 있는 34곳 중 동이 확인된 A~D동 1~3층 28곳을 손님 화면의 지도·층별 목록·가게 목록에 넣었습니다(대빵 오락실·오봉집·세븐일레븐은 기존 C동 거리 카드와 연결, 새로 25곳). `node scripts/build-timespace-stores.cjs`가 `src/data/storefrontCatalog.json`에서 `src/data/timespaceStores.ts`를 만듭니다.
- 앱의 가게 구조가 1~3층만 지원하므로 4층 이상·지하·동 미확인 6곳(송도한방병원, 빛나래에스테틱, 모바이오, 아이나래정신건강의학과의원, 밴스의원, 루틴치과의원)은 **간판 찾기**와 거리 사진 안 동·층별 가게 사진에서만 보입니다.
- 설명·메뉴·가격은 지어내지 않고 업종과 "현장 확인"만 넣었습니다. 지도 핀은 각 동 건물의 큰길 쪽에 놓은 개념도 배치이며 실제 위치가 아닙니다. 구역 이름은 핀과 겹치지 않도록 건물 바깥쪽으로 옮겼습니다.
- 가게 정보(2026-11-06 확인): 25곳 중 24곳은 사진 출처 페이지(매장 안내·예약 페이지·방문 후기)에 적힌 소개·대표 메뉴·가격·영업시간만 `src/data/timespaceStoreDetails.json`에 출처 URL·게시일과 함께 옮겼습니다. 화면에는 "○○ 공개 자료 기준 · 현재와 다를 수 있어요"를 함께 표시합니다. 가격이 적혀 있지 않은 메뉴는 "현장 확인"으로 둡니다. 텐퍼센트커피 송도타임스페이스점은 해당 지점 정보를 찾지 못해 다른 지점 정보를 쓰지 않고 업종만 표시합니다.
- 2026-11-06 피드백 반영: 상단 **간판 찾기** 탭을 뺐습니다. 간판 사진 34곳과 조사 기록은 그대로 두고, 거리 사진 화면의 **A·B·C·D동 가게 둘러보기**에서 봅니다. 가게 목록에는 전체/1층/2층/3층 선택과 층별 제목을 넣었습니다. 화면 표시 이름은 지점명(송도타임스페이스점 등)을 뺀 짧은 이름을 쓰고, 원래 상호는 조사 자료(`storefrontCatalog.json`)에 남아 있습니다.
