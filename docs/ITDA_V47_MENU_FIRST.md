# ITDA v4.7 — 첫 화면 + 상단 메뉴 중심 구조

## 디자인 원칙
- 메인·소비자·점주·관리자용에 각각 독립된 첫 화면을 제공한다.
- 첫 화면에서 아래로 스크롤해 기능을 찾지 않고 상단 메뉴를 눌러 화면을 전환한다.
- 지도 편집, 점포 입력, 결과 검토처럼 내용이 긴 **기능 화면 자체에는 스크롤이 남아 있다**. 중요한 데이터를 숨기지 않기 위해서다.
- 모든 화면의 시연용 데이터, Supabase 승인·게시 구조, 관리자 인증을 보존한다.
- 사진은 디자인 시연용 자산이며 실제 상권 사진으로 변경 가능하다.

## 접속과 메뉴
| 홈페이지 | 주소 | 메뉴 |
|---|---|---|
| 메인 | https://itda.ink | 홈 / 소개 / 서비스 / 이용 안내 |
| 소비자 | https://customer.itda.ink | 홈 / 지도 탐색 / 오늘의 발견 / 즐겨찾기 |
| 점주 | https://owner.itda.ink | 홈 / 홍보안 만들기 / 점주 로그인·제출 내역 |
| 관리자 | https://editor.itda.ink | 대시보드 / 점포 관리 / 지도 관리 / 거리 사진 / 홍보안 검토 / 백업·복원 |

메인, 소비자, 점주의 내부 메뉴는 `?view=` 쿼리로 화면을 전환한다. 브라우저의 뒤로 가기도 작동한다.
관리자는 `/editor`, `/catalog`, `/map-editor`, `/street-editor`, `/promotions`, `/editor?view=backup`을 그대로 이용한다.

## 유지한 것
- 소비자 가게 검색, 맛·멋·이벤트 필터, 즐겨찾기, 층별 지도, 거리 사진과 점포 상세, 관리자가 승인한 게시본 로드
- 점주 홍보안 시연, 점주 로그인, 제출 및 승인 요청, 승인·반려 이력
- 관리자 인증·세션·권한 확인, 점포·지도·사진 편집, Supabase 게시 및 홍보안 검토, 백업 복원
- 기존 서브도메인 구조와 데이터베이스 SQL

## 시연용 이미지 교체
`public/brand/bridge.webp` — 메인 배너 (가로형 인천 사진 권장)
`public/brand/songdo.webp` — 소비자용 탐색 관련 사진
`public/brand/sunset.webp` — 점주용 오렌지 홍보 배너
`public/brand/forest.webp` — 보조 이미지

동일한 이름의 파일로 교체하면 별도의 코드 수정 없이 업데이트 가능하다. 새 이미지를 넣기 전 저작권·초상권 및 배포 가능 여부를 확인한다.
매장별/촬영 지점별 사진은 기존 `/street-editor`를 통해 등록한다.

## 실제 실행 미리보기 (Windows)
1. ZIP 파일의 압축을 풀고 프로젝트 폴더로 들어간다.
2. Node.js LTS가 설치된 컴퓨터에서 `PREVIEW_START.bat`을 더블클릭한다.
3. 로컬 미리보기: `http://localhost:5173/welcome`, `/`, `/owner`, `/editor`.
4. 관리자 페이지는 인증이 유지되며, 로컬 Supabase 환경변수가 없으면 로그인 관문 뒤의 화면은 볼 수 없다.
5. `index.html` 더블클릭은 React/Vite 앱 실행 방법이 아니다.

## 배포 주의
최신 ZIP의 프로젝트 내부 파일을 기존 GitHub 저장소의 루트에 올린다. 기존 Vercel 프로젝트 및 DNS 설정은 변경하지 않는다.
본 버전은 Vite 종속성 다운로드가 차단된 환경에서 작성되었으므로 TypeScript/TSX 구문·CSS 파싱 및 내부 import 검사까지 수행했으며, 최종 `npm run build` / 실제 브라우저 검증은 배포 환경에서 확인해야 한다.
