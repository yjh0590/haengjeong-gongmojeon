## Street-view content workflow

1. Register stores in 매장 관리. Existing arbitrary store counts remain supported.
2. In 거리 사진, choose the point and direction, select a store, and click 선택한 가게 추가하기. Add and order all stores visible from that direction. Outlines are optional.
3. Upload the actual direction photo. Draw optional outlines if needed, then upload to the server.
4. Use 전체 게시 in 매장 관리 to publish the snapshot. Browser-only drafts remain private to that browser.
5. Customers rotate left/right or select a direction and browse stores three per page. Next-photo movement follows configured point links. This is linked-photo navigation, not stitched 360-degree panorama imagery.

Directional store lists are optional StreetNode.viewStores metadata. Legacy publications derive cards from their existing outline associations. Deleted store IDs are pruned when preparing a publication, and map reassignment removes obsolete directional lists. Older published snapshots remain valid.
