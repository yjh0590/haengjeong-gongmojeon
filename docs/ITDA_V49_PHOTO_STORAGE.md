# ITDA v4.9 — 서버 사진 업로드 / 공개 게시 안내

이 버전은 **v4.8 디자인·기능을 유지**하면서 Supabase Storage 사진 업로드와 점포 게시본 연동을 추가합니다. 기존 `supabase/001_publication.sql`, `002_owner_promotion_workflow.sql`은 다시 실행할 필요가 없습니다.

## 1. 사전 조건

- `editor.itda.ink` 관리자 로그인이 되는 상태
- Vercel에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` 설정 및 배포 완료
- Supabase의 `public.itda_admins`에 본인 관리자 계정 등록
- 사진은 JPG·PNG·WEBP, 20MB 이하. 인물 얼굴·차량 번호판 등은 업로드 **전에** 필요한 비식별 처리

## 2. Supabase Storage 준비 (최초 1회)

1. Supabase 대시보드에서 **SQL Editor → New query** 열기
2. 프로젝트 내 `supabase/003_public_media_storage.sql` 파일을 열어 전체 복사
3. SQL Editor에 붙여넣고 **Run**
4. 좌측 **Storage** 메뉴에서 `itda-media` 버킷이 생성됐는지 확인
5. 이 버킷은 **Public**: 업로드된 파일은 URL을 알면 곧바로 볼 수 있음. 업로드/수정 권한만 관리자에게 제한됨

테이블 `itda_publication`을 새로 만들거나 기존 데이터베이스를 초기화하지 마세요. 추가 환경변수나 API 비밀키도 필요하지 않습니다.

## 3. 거리 사진 등록 → 게시

1. `https://editor.itda.ink/street-editor` 접속
2. **촬영 지점 / 보는 방향** 선택
3. **JPG·PNG·WEBP 사진 등록**: 브라우저 임시 저장으로 사진과 외곽선 맞추기
4. 필요하면 **영역 저장**으로 가게 외곽선 지정
5. **현재 사진 서버 업로드** 버튼 클릭: Storage 버킷에 저장, 해당 방향의 서버 사진 연결이 초안에 기록
6. `https://editor.itda.ink/catalog` 접속 → **관리자 승인 · 전체 게시** 클릭
7. `https://customer.itda.ink`에서 새로고침하여 등록한 촬영 지점/방향 확인

**주의:** '서버 업로드'만으로 소비자 목록/거리뷰가 바뀌지 않습니다. 다만 Public 버킷의 사진 주소는 업로드 즉시 외부에서 접근 가능하므로 개인정보·저작권 검토 후 업로드하세요.

## 4. 전체 지도 배경 등록 (선택)

1. `https://editor.itda.ink/map-editor` 접속
2. **지도 이미지 등록** 후 지도 좌표·구역·동선 편집
3. 지도 이미지의 공개·재배포 권한을 실제로 확보한 경우에만 권한 확인 체크
4. **현재 지도 서버 업로드** 클릭
5. `/catalog`에서 **전체 게시**

**네이버 지도 캡처는 별도의 이용 허락 없이 서버에 업로드·재배포하지 마세요.** 직접 제작한 상권 지도 또는 공개 이용을 허용한 이미지를 사용하세요.

## 5. 작동 원리

- Storage 버킷: 이미지 원본 저장 (`itda-media`)
- 편집 주소의 브라우저 초안: 어느 촬영 지점·방향에 어느 서버 파일을 연결할지 저장
- `itda_publication` 게시본: 기존 점포/지도 데이터와 **이미지 경로만** 함께 기록
- 소비자 페이지: 게시된 경로를 공개 Storage 이미지 URL로 변환하여 표시
- 사진 교체: 새 사진 등록 → 서버 업로드 → 전체 게시. 이전 이미지 객체는 기존 게시본을 보호하기 위해 자동 삭제하지 않음

## 6. 주의와 제약

- 서버에 업로드한 이미지 연결 **초안은 해당 브라우저**의 localStorage에 남습니다. `editor.itda.ink`에서 전체 백업을 다운로드하세요. v4.9 백업 형식에는 서버 이미지 경로 정보도 포함됩니다.
- 초안 단계에서 다른 컴퓨터/브라우저와 자동 동기화하지는 않습니다. 승인된 공개 게시본은 모든 소비자에게 공통 제공됩니다.
- `/catalog`에서 **공개본을 초안으로 가져오기**를 누르면 이미 게시된 이미지 연결도 가져옵니다.
- 이전 v4.8 게시본에는 이미지 정보가 없어도 정상 작동하도록 유지했습니다.
- 이 버전은 **방향별 일반 사진** 연결입니다. 360도 파노라마 촬영·회전 기능, 실제 실측 길찾기, 사진 속 가게 자동 인식 AI는 아직 구현되지 않았습니다.
- 파일 크기·개수·호스팅 트래픽은 Supabase 플랜 용량과 요금 정책을 따릅니다.
- 이미 공개 중인 이미지를 Supabase Storage에서 직접 삭제하면 소비자 화면의 사진이 깨질 수 있습니다. 관리자 화면의 '연결 해제'는 파일을 삭제하지 않습니다.

## 7. 문제 해결

- `Bucket not found`: `003_public_media_storage.sql` 미실행 또는 다른 Supabase 프로젝트 연결
- `403 Unauthorized / row-level security`: 로그인 계정의 `itda_admins` 등록 및 Storage 정책 확인
- `413 Entity Too Large`: 20MB 이하 이미지로 압축하고 프로젝트 파일 크기 제한 확인
- 서버 사진은 뜨는데 소비자에서 안 보임: `/catalog` 전체 게시 여부, 같은 Supabase URL, 새로고침 확인
- 외곽선이 맞지 않음: 업로드한 이미지 기준으로 다시 꼭짓점 지정 → 영역 저장 → 전체 게시
