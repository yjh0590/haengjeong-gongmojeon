# ITDA(잇다) 점주용 사용 가이드

**대상:** 점포 정보를 기반으로 홍보 문구를 만들어 보고 관리자에게 검토 요청할 점주  
**접속 주소:** https://owner.itda.ink  
**기준 버전:** ITDA v5.2 · 2026-11-04

## 1. 어떤 서비스인가요?
매장의 메뉴·분위기·홍보 목적을 바탕으로 **홍보 아이디어, 문구, 짧은 영상 대본**을 시연하고, 계정이 연결된 점주라면 관리자에게 홍보안을 제출할 수 있습니다.

> **중요:** 현 버전의 'AI 마케팅 제안'은 **예시 템플릿 기반 시연**입니다. 생성형 AI API가 실시간으로 문구를 생성하는 기능은 아직 연동되지 않았습니다.

## 2. 계정 없이 사용해 보기
1. `owner.itda.ink`에 접속합니다.
2. 시범 점포를 선택합니다.
3. 가게 상황, 홍보 목표, 원하는 조건 등을 입력하거나 선택합니다.
4. **AI 프로모션 생성**을 눌러 제안된 콘텐츠를 확인합니다.
5. 원하는 결과를 검토하고 **이 홍보안 시연 초안 저장**을 선택할 수 있습니다.

이 과정은 시연·초안 작성이며 **소비자 홈페이지에 자동 게시되지 않습니다**.

## 3. 점주 로그인과 실제 제출
1. 운영자에게 **Supabase Auth 점주 계정 발급 및 담당 점포 배정**을 요청합니다.
2. 페이지 상단에서 점주 이메일과 비밀번호로 로그인합니다.
3. 내 담당 점포인지 확인합니다. 배정되지 않은 점포는 홍보안을 제출할 수 없습니다.
4. 홍보 내용을 결정하고 **시연 초안 저장**을 진행합니다.
5. **홍보 종료일**을 지정합니다.
6. **검토 요청 보내기**를 눌러 관리자에게 제출합니다.
7. 상단 **내 홍보안 제출 내역**에서 `검토 중 / 승인됨 / 반려됨` 상태를 확인합니다.
8. 관리자 승인 후 소비자용 서비스의 이벤트 문구에 반영됩니다.

## 4. 좋은 홍보안 작성 방법
- **메뉴/서비스:** 실제 제공하는 대표 상품을 적습니다.
- **고객:** 학생·직장인 등 목표 고객을 특정합니다.
- **시간·조건:** 혜택의 적용 기간과 학생 인증 등 조건을 구체적으로 적습니다.
- **사실 확인:** 할인 가격·서비스 제공 여부를 직접 검증합니다.
- **표현 검수:** 과장·허위 문구, 타인 사진 무단 사용을 피합니다.

예: `오후 5~8시 / 학생증 확인 / 음료 제공`은 실제 점주가 승인한 행사일 때만 게시할 수 있습니다.

## 5. 유의사항
- 점포 생성·수정은 **관리자용 점포 관리**에서 진행합니다.
- **홍보안 제출**과 **최종 공개**는 다른 단계입니다. 점주의 제출만으로 공개되지 않습니다.
- 같은 점포에 `검토 중`인 홍보안이 있는 동안 새 제출이 제한될 수 있습니다.
- 온라인으로 게시된 점포 데이터가 없으면 로그인 또는 제출이 제한될 수 있습니다.
- 이미지 자동 생성, 숏폼 자동 제작 및 완전 자동 게시 등은 현 단계에서 **향후 계획 기능**입니다.

## 6. 문제가 생기면
- **로그인할 수 없어요:** 관리자에게 계정 발급·점포 배정·Supabase 설정을 확인해 달라고 요청하세요.
- **제출 버튼이 눌리지 않아요:** 로그인 여부, 담당 점포, 게시 데이터, 검토 중인 요청, 홍보 종료일을 확인하세요.
- **승인했는데 안 보여요:** 실제 소비자 화면에서 해당 점포 이벤트 문구를 확인하고, 승인 여부 및 종료일을 점검하세요.
