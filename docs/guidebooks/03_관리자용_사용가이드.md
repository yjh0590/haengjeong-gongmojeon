# ITDA(잇다) 관리자용 운영 가이드

**대상:** 점포·지도·촬영 지점·거리 사진·홍보안을 관리하는 운영자  
**접속 주소:** https://editor.itda.ink  
**기준 버전:** ITDA v5.2 · 2026-11-04

## 1. 관리자 역할과 시작하기
관리자는 정확한 점포 정보를 등록하고, 지도와 사진을 연결해, 검토한 자료만 소비자에게 공개합니다.
1. `editor.itda.ink`에 접속합니다.
2. **Supabase Auth 관리자 계정**으로 로그인합니다. 승인된 관리자 계정이어야 편집/게시 권한이 있습니다.
3. 대시보드에서 **점포 등록·게시 / 전체 지도 편집 / 거리 사진 편집 / 홍보안 검토·승인** 메뉴로 이동합니다.

## 2. 점포 등록·수정 (`/catalog`)
1. **점포 목록 → 추가** 또는 기존 점포를 선택합니다.
2. 이름, 업종(`맛`/`멋`), 동, 층(1·2·3층), 호수, 설명, 대표 메뉴·가격, 태그 등을 입력합니다.
3. 입력한 내용이 **브라우저 임시 초안**에 저장되었는지 확인합니다.
4. 실제 공개 전까지 **전체 게시**를 누르지 않으면 소비자 사이트에 반영되지 않습니다.

## 3. 지도·촬영 지점 편집 (`/map-editor`)
1. 상권 안내도에서 **상권 경계**, **보행 통로**, **촬영 지점**, **점포 위치** 모드를 선택합니다.
2. 실제 현장 자료를 기준으로 지도 위 위치를 클릭해 좌표를 등록합니다.
3. 각 **촬영 지점**의 이름과 방향별 연결 지점을 설정합니다.
4. **점포 위치**에서 실제 점포와 촬영 지점을 연결합니다.
5. 층별 점포 필터를 사용해 1·2·3층 좌표를 검토합니다.
6. **변경사항 저장**을 누릅니다.
7. **현장 자료·연결 점검**에서 미등록 사진, 미연결 점포, 좌표 누락, 경로 문제를 확인합니다.
8. 필요하면 **촬영 계획표 CSV 내려받기**로 현장 촬영 계획을 만듭니다.

현재 지도는 시범 도식이며, 실측 길찾기를 보장하지 않습니다. 저작권이 있는 지도 캡처는 별도 사용 허락 없이 공개하지 마세요.

## 4. 거리 사진 등록 (`/street-editor`)
1. 촬영 지점과 `앞·뒤·왼쪽·오른쪽` 방향을 고릅니다.
2. **JPG·PNG·WEBP 사진 등록**을 눌러 브라우저 임시 사진을 올립니다.
3. 가게가 보이는 경우 사진 위의 영역 꼭짓점을 차례로 클릭한 뒤 **영역 저장**을 누릅니다. 영역은 3개 이상 점이 필요합니다.
4. **현재 사진 서버 업로드**를 눌러 Supabase Storage에 원본 파일을 등록합니다.
5. 업로드 성공 메시지와 서버 사진 상태를 확인합니다.
6. 필요한 방향만큼 반복합니다.

**보안 주의:** 공개 Storage 버킷에서는 **파일 주소를 아는 사람이 게시 전에도 사진을 볼 수 있습니다**. 촬영 전에 이용 허락·저작권을 확인하고 얼굴·번호판 등은 비식별 처리하세요.

## 5. 점주 홍보안 검토 (`/promotions`)
1. 점주가 제출한 홍보안을 엽니다.
2. 상품·행사 조건, 가격, 날짜, 과장 여부, 점주 동의를 확인합니다.
3. 사실이 맞으면 **승인 · 소비자 게시**, 수정이 필요하면 **반려**를 선택합니다.
4. 승인된 홍보 문구는 소비자 홈페이지에 반영될 수 있습니다. 진행 종료일 이후에는 숨겨집니다.

점주 로그인·제출 기능은 Supabase의 점주 계정 배정과 관련 SQL 설정이 필요합니다.

## 6. 소비자용 전체 게시 (`/catalog`)
1. 저장된 점포·지도 좌표·사진 연결·영역 데이터를 다시 확인합니다.
2. 사진 원본이 **Supabase Storage에 업로드**되었는지 확인합니다. 브라우저 임시 사진은 서버 게시에 포함되지 않습니다.
3. **관리자 승인 · 전체 게시**를 선택합니다.
4. 확인창에서 공개할 데이터 개수를 검토하고 게시합니다.
5. `https://customer.itda.ink`에서 강제 새로고침해 지도, 층, 카드, 거리 사진이 제대로 노출되는지 확인합니다.

**주의:** 점주 홍보안 별도 승인과 관리자 **전체 데이터 게시**는 서로 다른 흐름입니다. 전체 게시 전에 기존 공개본과 최신 승인 이벤트의 충돌 여부를 확인하세요.

## 7. 백업·복원
- 대시보드의 **사진 포함 전체 백업**을 주기적으로 내려받습니다.
- 복원은 **현재 브라우저 초안을 덮어쓸 수 있으므로** 기존 작업과 비교한 뒤 사용합니다.
- 지도 설정 JSON에는 **이미지가 포함되지 않을 수 있습니다**. 사진 포함 백업과 지도 설정 내보내기는 목적이 다릅니다.
- 서버 사진 공개 URL 연결과 파일 원본은 구분해서 관리하세요.

## 8. 게시 전 최종 체크리스트
- [ ] 점포명·위치·층수·가격·이벤트 조건 검증
- [ ] 건물·점포 위치 및 촬영 지점 연결 확인
- [ ] 사진 4방향 등록 상태 및 개인정보 비식별 처리
- [ ] 지도·사진 저작권 및 공개 허락 확인
- [ ] 모바일 소비자 화면에서 카드·검색·층 선택 확인
- [ ] 게시 직전 백업 저장
- [ ] 전체 게시 이후 실제 소비자 화면 점검

## 9. 문제가 생기면
- **관리자 로그인이 안 돼요:** Supabase Auth 계정과 관리자 명단 등록 상태를 확인합니다.
- **사진 업로드 오류:** Storage 버킷 `itda-media`, 파일 형식, 네트워크, Storage 정책을 확인합니다.
- **사진이 소비자에게 안 보여요:** 서버 업로드 완료 여부, 전체 게시 여부, 해당 지점·방향 연결을 확인합니다.
- **다른 기기에서 초안이 안 보여요:** 브라우저 초안은 기기 간 자동 공유되지 않습니다. 백업/게시 과정을 사용하세요.
