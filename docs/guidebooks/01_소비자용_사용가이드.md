# ITDA(잇다) 소비자용 사용 가이드

**대상:** 타임스페이스를 둘러보거나 가게를 찾는 방문객  
**접속 주소:** https://customer.itda.ink  
**기준 버전:** ITDA v5.2 · 2026-11-04

## 1. ITDA가 무엇인가요?
ITDA는 지역의 가게를 **지도와 거리 사진으로 발견**하도록 돕는 상권 탐색 서비스입니다. 현재 송도 타임스페이스를 시범 구역으로 사용합니다. 네이버지도처럼 실시간 길 안내를 하는 서비스는 아닙니다.

## 2. 시작하기
1. 브라우저에서 `customer.itda.ink`를 엽니다.
2. 첫 화면에서 **지도에서 가게 찾기**를 눌러 지도 영역으로 이동합니다.
3. **1층 / 2층 / 3층** 버튼을 눌러 원하는 층을 고릅니다.
4. 원하는 가게의 **지도 번호·지점 목록·가게 카드**를 눌러 정보를 봅니다.

## 3. 주요 기능
- **검색:** 가게 이름·업종·키워드를 입력합니다.
- **필터:** `전체`, `맛`, `멋`, `이벤트`와 **저장한 가게**를 이용합니다.
- **건물별 보기:** 등록된 건물 중 하나를 고릅니다.
- **층별 지도:** 선택한 층의 점포만 지도와 목록에 표시합니다.
- **거리 사진:** 지도에서 촬영 지점을 누르고 `앞·오른쪽·뒤·왼쪽` 버튼을 선택합니다. 초록 점은 사진이 등록된 방향을 뜻합니다.
- **다음 지점:** 연결된 촬영 지점이 있다면 **○번 지점** 이동 버튼으로 사진을 넘깁니다.
- **가게 카드:** 거리 사진 아래 카드에서 점포 사진(있을 때), 소개, 위치, 대표 정보, 특징을 비교합니다. **최대 3개**가 우선 표시되며 등록 점포가 적으면 3개 미만일 수 있습니다.
- **상세 정보:** 가게 카드를 누르면 대표 메뉴·가격·태그·이벤트 등을 확인할 수 있습니다.
- **즐겨찾기:** 하트/저장 버튼으로 가게를 보관합니다. 현재 저장 기능은 같은 브라우저에 의존하므로 다른 기기와 자동 동기화되지 않을 수 있습니다.

## 4. 따라 해 보기: 2층 가게 찾기
1. **지도에서 가게 찾기**를 선택합니다.
2. 지도의 오른쪽에서 **2층**을 선택합니다.
3. 2층 지점 중 원하는 번호나 가게명을 선택합니다.
4. 거리 사진에서 `앞/좌/우/뒤`를 눌러 외관을 확인합니다.
5. 가게 카드에서 **가게 상세**를 열거나 즐겨찾기에 저장합니다.

## 5. 알아두세요
- 현 단계의 지도와 일부 점포·이벤트 정보는 **시범 데이터**이며, 실측 좌표 및 실시간 영업 정보가 아닐 수 있습니다.
- 등록된 사진은 **일반 방향별 사진**입니다. 360도 실시간 거리뷰가 아닙니다.
- 2·3층 점포도 **1층 외관 또는 출입구 사진**에 연결될 수 있습니다. 실제 계단·엘리베이터 경로는 현장에서 확인하세요.
- 가게의 현재 영업 여부, 가격, 이벤트 적용 여부는 직접 확인해야 합니다.
- 일부 카드에는 사진 대신 **사진 미등록 자리**가 나타날 수 있습니다.

## 6. 문제가 생기면
- **사진이 안 나와요:** 다른 촬영 지점이나 방향을 눌러 보세요. 해당 사진이 미등록일 수 있습니다.
- **가게가 안 나와요:** 층·건물·검색어·카테고리·즐겨찾기 필터를 확인하세요.
- **내용이 시범이라고 떠요:** 서버 게시가 없거나 연결이 안 된 상태일 수 있습니다. 실제 영업 정보로 사용하지 마세요.
