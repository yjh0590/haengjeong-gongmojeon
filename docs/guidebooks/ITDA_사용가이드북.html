ITDA(잇다) 소비자용 사용 가이드

대상: 타임스페이스를 둘러보거나 가게를 찾는 방문객

접속 주소: https://customer.itda.ink

기준 버전: ITDA v5.2 · 2026-11-04

1. ITDA가 무엇인가요?

ITDA는 지역의 가게를 지도와 거리 사진으로 발견하도록 돕는 상권 탐색 서비스입니다. 현재 송도 타임스페이스를 시범 구역으로 사용합니다. 네이버지도처럼 실시간 길 안내를 하는 서비스는 아닙니다.

2. 시작하기

  • 브라우저에서 customer.itda.ink를 엽니다.
  • 첫 화면에서 지도에서 가게 찾기를 눌러 지도 영역으로 이동합니다.
  • 1층 / 2층 / 3층 버튼을 눌러 원하는 층을 고릅니다.
  • 원하는 가게의 지도 번호·지점 목록·가게 카드를 눌러 정보를 봅니다.

3. 주요 기능

  • 검색: 가게 이름·업종·키워드를 입력합니다.
  • 필터: 전체, 맛, 멋, 이벤트와 저장한 가게를 이용합니다.
  • 건물별 보기: 등록된 건물 중 하나를 고릅니다.
  • 층별 지도: 선택한 층의 점포만 지도와 목록에 표시합니다.
  • 거리 사진: 지도에서 촬영 지점을 누르고 앞·오른쪽·뒤·왼쪽 버튼을 선택합니다. 초록 점은 사진이 등록된 방향을 뜻합니다.
  • 다음 지점: 연결된 촬영 지점이 있다면 ○번 지점 이동 버튼으로 사진을 넘깁니다.
  • 가게 카드: 거리 사진 아래 카드에서 점포 사진(있을 때), 소개, 위치, 대표 정보, 특징을 비교합니다. 최대 3개가 우선 표시되며 등록 점포가 적으면 3개 미만일 수 있습니다.
  • 상세 정보: 가게 카드를 누르면 대표 메뉴·가격·태그·이벤트 등을 확인할 수 있습니다.
  • 즐겨찾기: 하트/저장 버튼으로 가게를 보관합니다. 현재 저장 기능은 같은 브라우저에 의존하므로 다른 기기와 자동 동기화되지 않을 수 있습니다.

4. 따라 해 보기: 2층 가게 찾기

  • 지도에서 가게 찾기를 선택합니다.
  • 지도의 오른쪽에서 2층을 선택합니다.
  • 2층 지점 중 원하는 번호나 가게명을 선택합니다.
  • 거리 사진에서 앞/좌/우/뒤를 눌러 외관을 확인합니다.
  • 가게 카드에서 가게 상세를 열거나 즐겨찾기에 저장합니다.

5. 알아두세요

  • 현 단계의 지도와 일부 점포·이벤트 정보는 시범 데이터이며, 실측 좌표 및 실시간 영업 정보가 아닐 수 있습니다.
  • 등록된 사진은 일반 방향별 사진입니다. 360도 실시간 거리뷰가 아닙니다.
  • 2·3층 점포도 1층 외관 또는 출입구 사진에 연결될 수 있습니다. 실제 계단·엘리베이터 경로는 현장에서 확인하세요.
  • 가게의 현재 영업 여부, 가격, 이벤트 적용 여부는 직접 확인해야 합니다.
  • 일부 카드에는 사진 대신 사진 미등록 자리가 나타날 수 있습니다.

6. 문제가 생기면

  • 사진이 안 나와요: 다른 촬영 지점이나 방향을 눌러 보세요. 해당 사진이 미등록일 수 있습니다.
  • 가게가 안 나와요: 층·건물·검색어·카테고리·즐겨찾기 필터를 확인하세요.
  • 내용이 시범이라고 떠요: 서버 게시가 없거나 연결이 안 된 상태일 수 있습니다. 실제 영업 정보로 사용하지 마세요.

ITDA(잇다) 점주용 사용 가이드

대상: 점포 정보를 기반으로 홍보 문구를 만들어 보고 관리자에게 검토 요청할 점주

접속 주소: https://owner.itda.ink

기준 버전: ITDA v5.2 · 2026-11-04

1. 어떤 서비스인가요?

매장의 메뉴·분위기·홍보 목적을 바탕으로 홍보 아이디어, 문구, 짧은 영상 대본을 시연하고, 계정이 연결된 점주라면 관리자에게 홍보안을 제출할 수 있습니다.

중요: 현 버전의 'AI 마케팅 제안'은 예시 템플릿 기반 시연입니다. 생성형 AI API가 실시간으로 문구를 생성하는 기능은 아직 연동되지 않았습니다.

2. 계정 없이 사용해 보기

  • owner.itda.ink에 접속합니다.
  • 시범 점포를 선택합니다.
  • 가게 상황, 홍보 목표, 원하는 조건 등을 입력하거나 선택합니다.
  • AI 프로모션 생성을 눌러 제안된 콘텐츠를 확인합니다.
  • 원하는 결과를 검토하고 이 홍보안 시연 초안 저장을 선택할 수 있습니다.

이 과정은 시연·초안 작성이며 소비자 홈페이지에 자동 게시되지 않습니다.

3. 점주 로그인과 실제 제출

  • 운영자에게 Supabase Auth 점주 계정 발급 및 담당 점포 배정을 요청합니다.
  • 페이지 상단에서 점주 이메일과 비밀번호로 로그인합니다.
  • 내 담당 점포인지 확인합니다. 배정되지 않은 점포는 홍보안을 제출할 수 없습니다.
  • 홍보 내용을 결정하고 시연 초안 저장을 진행합니다.
  • 홍보 종료일을 지정합니다.
  • 검토 요청 보내기를 눌러 관리자에게 제출합니다.
  • 상단 내 홍보안 제출 내역에서 검토 중 / 승인됨 / 반려됨 상태를 확인합니다.
  • 관리자 승인 후 소비자용 서비스의 이벤트 문구에 반영됩니다.

4. 좋은 홍보안 작성 방법

  • 메뉴/서비스: 실제 제공하는 대표 상품을 적습니다.
  • 고객: 학생·직장인 등 목표 고객을 특정합니다.
  • 시간·조건: 혜택의 적용 기간과 학생 인증 등 조건을 구체적으로 적습니다.
  • 사실 확인: 할인 가격·서비스 제공 여부를 직접 검증합니다.
  • 표현 검수: 과장·허위 문구, 타인 사진 무단 사용을 피합니다.

예: 오후 5~8시 / 학생증 확인 / 음료 제공은 실제 점주가 승인한 행사일 때만 게시할 수 있습니다.

5. 유의사항

  • 점포 생성·수정은 관리자용 점포 관리에서 진행합니다.
  • 홍보안 제출과 최종 공개는 다른 단계입니다. 점주의 제출만으로 공개되지 않습니다.
  • 같은 점포에 검토 중인 홍보안이 있는 동안 새 제출이 제한될 수 있습니다.
  • 온라인으로 게시된 점포 데이터가 없으면 로그인 또는 제출이 제한될 수 있습니다.
  • 이미지 자동 생성, 숏폼 자동 제작 및 완전 자동 게시 등은 현 단계에서 향후 계획 기능입니다.

6. 문제가 생기면

  • 로그인할 수 없어요: 관리자에게 계정 발급·점포 배정·Supabase 설정을 확인해 달라고 요청하세요.
  • 제출 버튼이 눌리지 않아요: 로그인 여부, 담당 점포, 게시 데이터, 검토 중인 요청, 홍보 종료일을 확인하세요.
  • 승인했는데 안 보여요: 실제 소비자 화면에서 해당 점포 이벤트 문구를 확인하고, 승인 여부 및 종료일을 점검하세요.

ITDA(잇다) 관리자용 운영 가이드

대상: 점포·지도·촬영 지점·거리 사진·홍보안을 관리하는 운영자

접속 주소: https://editor.itda.ink

기준 버전: ITDA v5.2 · 2026-11-04

1. 관리자 역할과 시작하기

관리자는 정확한 점포 정보를 등록하고, 지도와 사진을 연결해, 검토한 자료만 소비자에게 공개합니다.

  • editor.itda.ink에 접속합니다.
  • Supabase Auth 관리자 계정으로 로그인합니다. 승인된 관리자 계정이어야 편집/게시 권한이 있습니다.
  • 대시보드에서 점포 등록·게시 / 전체 지도 편집 / 거리 사진 편집 / 홍보안 검토·승인 메뉴로 이동합니다.

2. 점포 등록·수정 (`/catalog`)

  • 점포 목록 → 추가 또는 기존 점포를 선택합니다.
  • 이름, 업종(맛/멋), 동, 층(1·2·3층), 호수, 설명, 대표 메뉴·가격, 태그 등을 입력합니다.
  • 입력한 내용이 브라우저 임시 초안에 저장되었는지 확인합니다.
  • 실제 공개 전까지 전체 게시를 누르지 않으면 소비자 사이트에 반영되지 않습니다.

3. 지도·촬영 지점 편집 (`/map-editor`)

  • 상권 안내도에서 상권 경계, 보행 통로, 촬영 지점, 점포 위치 모드를 선택합니다.
  • 실제 현장 자료를 기준으로 지도 위 위치를 클릭해 좌표를 등록합니다.
  • 각 촬영 지점의 이름과 방향별 연결 지점을 설정합니다.
  • 점포 위치에서 실제 점포와 촬영 지점을 연결합니다.
  • 층별 점포 필터를 사용해 1·2·3층 좌표를 검토합니다.
  • 변경사항 저장을 누릅니다.
  • 현장 자료·연결 점검에서 미등록 사진, 미연결 점포, 좌표 누락, 경로 문제를 확인합니다.
  • 필요하면 촬영 계획표 CSV 내려받기로 현장 촬영 계획을 만듭니다.

현재 지도는 시범 도식이며, 실측 길찾기를 보장하지 않습니다. 저작권이 있는 지도 캡처는 별도 사용 허락 없이 공개하지 마세요.

4. 거리 사진 등록 (`/street-editor`)

  • 촬영 지점과 앞·뒤·왼쪽·오른쪽 방향을 고릅니다.
  • JPG·PNG·WEBP 사진 등록을 눌러 브라우저 임시 사진을 올립니다.
  • 가게가 보이는 경우 사진 위의 영역 꼭짓점을 차례로 클릭한 뒤 영역 저장을 누릅니다. 영역은 3개 이상 점이 필요합니다.
  • 현재 사진 서버 업로드를 눌러 Supabase Storage에 원본 파일을 등록합니다.
  • 업로드 성공 메시지와 서버 사진 상태를 확인합니다.
  • 필요한 방향만큼 반복합니다.

보안 주의: 공개 Storage 버킷에서는 파일 주소를 아는 사람이 게시 전에도 사진을 볼 수 있습니다. 촬영 전에 이용 허락·저작권을 확인하고 얼굴·번호판 등은 비식별 처리하세요.

5. 점주 홍보안 검토 (`/promotions`)

  • 점주가 제출한 홍보안을 엽니다.
  • 상품·행사 조건, 가격, 날짜, 과장 여부, 점주 동의를 확인합니다.
  • 사실이 맞으면 승인 · 소비자 게시, 수정이 필요하면 반려를 선택합니다.
  • 승인된 홍보 문구는 소비자 홈페이지에 반영될 수 있습니다. 진행 종료일 이후에는 숨겨집니다.

점주 로그인·제출 기능은 Supabase의 점주 계정 배정과 관련 SQL 설정이 필요합니다.

6. 소비자용 전체 게시 (`/catalog`)

  • 저장된 점포·지도 좌표·사진 연결·영역 데이터를 다시 확인합니다.
  • 사진 원본이 Supabase Storage에 업로드되었는지 확인합니다. 브라우저 임시 사진은 서버 게시에 포함되지 않습니다.
  • 관리자 승인 · 전체 게시를 선택합니다.
  • 확인창에서 공개할 데이터 개수를 검토하고 게시합니다.
  • https://customer.itda.ink에서 강제 새로고침해 지도, 층, 카드, 거리 사진이 제대로 노출되는지 확인합니다.

주의: 점주 홍보안 별도 승인과 관리자 전체 데이터 게시는 서로 다른 흐름입니다. 전체 게시 전에 기존 공개본과 최신 승인 이벤트의 충돌 여부를 확인하세요.

7. 백업·복원

  • 대시보드의 사진 포함 전체 백업을 주기적으로 내려받습니다.
  • 복원은 현재 브라우저 초안을 덮어쓸 수 있으므로 기존 작업과 비교한 뒤 사용합니다.
  • 지도 설정 JSON에는 이미지가 포함되지 않을 수 있습니다. 사진 포함 백업과 지도 설정 내보내기는 목적이 다릅니다.
  • 서버 사진 공개 URL 연결과 파일 원본은 구분해서 관리하세요.

8. 게시 전 최종 체크리스트

  • [ ] 점포명·위치·층수·가격·이벤트 조건 검증
  • [ ] 건물·점포 위치 및 촬영 지점 연결 확인
  • [ ] 사진 4방향 등록 상태 및 개인정보 비식별 처리
  • [ ] 지도·사진 저작권 및 공개 허락 확인
  • [ ] 모바일 소비자 화면에서 카드·검색·층 선택 확인
  • [ ] 게시 직전 백업 저장
  • [ ] 전체 게시 이후 실제 소비자 화면 점검

9. 문제가 생기면

  • 관리자 로그인이 안 돼요: Supabase Auth 계정과 관리자 명단 등록 상태를 확인합니다.
  • 사진 업로드 오류: Storage 버킷 itda-media, 파일 형식, 네트워크, Storage 정책을 확인합니다.
  • 사진이 소비자에게 안 보여요: 서버 업로드 완료 여부, 전체 게시 여부, 해당 지점·방향 연결을 확인합니다.
