# ITDA v5.1 · 층별 안내도 전환

## 목적
기존에 지도 위에 여러 층의 점포 핀을 한꺼번에 표시하던 방식을 폐지하고, 지도 오른쪽에서 `1층 / 2층 / 3층` 버튼으로 전환합니다.

## 소비자용 변경
- 기본 선택은 1층입니다. 지도 위에 선택한 층의 점포만 표시합니다.
- 오른쪽에 층 선택 및 현재 층의 점포 번호·이름 목록을 추가했습니다.
- 번호는 **현재 선택한 층·건물 내에 등록된 점포를 ID 순서로 정렬한 표시용 번호**입니다. DB의 점포 고유 ID는 변경되지 않습니다. 검색 필터가 적용되어도 번호는 유지됩니다.
- 지점 번호(작은 네모 핀)를 누르거나 오른쪽 지점 목록을 누르면 기존 `focusStore` 동작으로 거리 사진이 연결됩니다.
- 큰 파란색 원은 점포 핀이 아니라 **사진 촬영 지점 번호**입니다. 사진 촬영 지점에는 층 정보가 없으므로 선택 층의 점포에 연결된 사진 촬영 지점만 표시합니다. 동일 촬영 지점이 여러 층에 보일 수 있고 사진은 해당 층의 내부 사진이 아니라 외관 사진일 수 있습니다.
- 건물 선택, 검색, 맛/멋/이벤트, 즐겨찾기, 거리뷰 방향 선택, 관리자 게시 데이터와 Supabase Storage 연동은 유지했습니다.
- 관리자용 지도 편집기는 변경하지 않았습니다. 좌표 데이터와 서버 DB 마이그레이션도 필요 없습니다.

## 시연 점포의 초기 표시
1층: 점포 1, 2 → 층 내 1·2번. 2층: 점포 3, 4 → 층 내 1·2번. 3층: 점포 5, 6 → 층 내 1·2번. **없는 3번 지점을 임의 생성하지 않습니다.** 점포가 늘어나면 다음 번호가 자동으로 표시됩니다.

## 테스트
1. `https://customer.itda.ink`에서 지도 안내도로 이동합니다.
2. 기본은 1층이고, 2층/3층 버튼을 선택하면 해당 층의 점포만 남는지 확인합니다.
3. 지도 핀/오른쪽 지점 목록에서 점포를 선택해 해당 거리 사진이 열리는지 확인합니다.
4. 건물 필터, 저장한 가게 필터, 관리자 등록 지도 보기와 모바일 너비도 확인합니다.

## 주의
지도 건물 모양, 층별 위치 좌표는 기존 v5.0과 마찬가지로 **시연용**이며 실제 평면도·실측 정보가 아닙니다. 현장 조사 후 관리자 지도 편집기에서 업데이트해야 합니다.

## 배포
GitHub Desktop에서 기존 저장소에 변경된 파일을 복사해 Commit → Push 후 Vercel 배포를 확인합니다. 추가 SQL은 없습니다.
