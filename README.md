# ITDA · 맛&멋 AI Street v3

기존 소비자·점주·지도 편집·거리 사진 편집 기능을 유지하면서 **itda.link 주소별 역할 분리**, 독립 메인 포털, 관리자 대시보드, 사진 포함 JSON 백업·복원을 추가한 버전입니다.

## 실행 / 배포

```bash
npm ci
npm run dev
npm run build
```

기존 GitHub 저장소의 소스코드를 교체하여 Vercel에서 배포합니다. 새 도메인을 연결하지 않아도 기존 `*.vercel.app` 주소의 화면이 유지됩니다.

## 기본 주소

| 새 주소 | 역할 | 도메인 설정 전 기존 Vercel 경로 |
| --- | --- | --- |
| `itda.link` | 브랜드 메인 포털 | `/welcome` |
| `customer.itda.link` | 소비자용 | `/` |
| `owner.itda.link` | 점주 시연 | `/owner` |
| `editor.itda.link` | 관리자 작업 공간 | `/editor` |
| `editor.itda.link/map-editor` | 전체 구역 / 촬영 지점 편집 | `/map-editor` |
| `editor.itda.link/street-editor` | 거리 사진 / 점포 외곽선 편집 | `/street-editor` |

## 이번에 추가된 내용

1. **도메인 분기**: 한 Vercel 프로젝트 안에서 방문한 서브도메인에 맞는 화면을 자동 표시.
2. **ITDA 메인 포털**: 소비자용·점주용 진입 링크 (관리자용은 별도 주소 접속).
3. **관리자 대시보드**: 지도·사진 편집을 한 곳에서 관리. 촬영 지점, 브라우저 등록 이미지, 외곽선 수를 확인.
4. **사진 포함 백업**: 지도·촬영 지점·가게 외곽선·임시 등록 사진을 JSON 파일로 내보내고 가져오기.
5. **동일 출처 시연 미리보기**: 편집 데이터와 홍보 승인 내용을 **각각 저장한 주소에서** 소비자 화면으로 검토 가능.
6. **시연 정보 고지**: 점주 제안 문구가 실제 AI 생성이 아닌 예시이며, 미구현/미검증 기능은 명확히 표시.
7. 기존 지도·층 선택(전체/1/2/3층)·촬영 지점·가게 윤곽선·즐겨찾기 및 점주용 화면 유지.

## 중요 주의

**관리자 로그인, 실제 AI 생성, 서버 DB, 도메인 간 데이터 공유, 사진 자동 게시, 공공데이터 API 자동 갱신, 360° 거리뷰는 아직 구현되지 않았습니다.** 브라우저에 저장한 임시 데이터는 다른 서브도메인이나 다른 사람에게 자동 공유되지 않습니다. 사진의 공개 사용 권한을 확인하세요.

도메인 DNS 설정과 작업 데이터 이관 방법은 [`docs/ITDA_DOMAIN_AND_EDITOR.md`](docs/ITDA_DOMAIN_AND_EDITOR.md), 지도 편집 과정은 [`docs/WHOLE_AREA_PLAN.md`](docs/WHOLE_AREA_PLAN.md)를 참고하세요.
