# ITDA · 맛&멋 AI Street v4.1

v3 소비자·점주·지도·사진 편집 기능을 유지하면서 **점포 등록·수정/삭제, 층·호수 관리, 관리자 승인 게시, Supabase 기반 소비자 공통 데이터 조회(연결 시)** 기능을 추가했습니다. 서버를 연결하지 않아도 브라우저 초안 미리보기가 가능합니다.

## 실행 / 배포

```bash
npm ci
npm run dev
npm run build
```

기존 GitHub 저장소의 소스코드를 교체하여 Vercel에서 배포합니다. 새 도메인을 연결하지 않아도 기존 `*.vercel.app` 주소의 화면이 유지됩니다.

비밀번호 설정과 초대 링크 복구 페이지가 추가되었습니다. `/reset-password`에서 메일을 다시 요청하고 링크를 통해 비밀번호를 지정할 수 있습니다. 자세한 내용은 `docs/ITDA_V4_1_ACCOUNT_SETUP.md`를 확인하세요.

## v4 추가 기능

1. **점포 편집 (`/catalog`)**: 가게 추가·삭제·수정, 맛/멋 구분, 동·층·호수, 이벤트, 태그, 대표 메뉴를 브라우저 초안으로 관리.
2. **지도·가게 연결**: 지도와 사진 편집기의 점포 목록이 동일한 브라우저 초안 정보를 사용.
3. **일괄 게시**: Supabase 설정과 관리자 인증을 완료하면 **점포·지도 좌표·보행 통로·촬영 지점·가게 외곽선**을 하나의 공개 게시본으로 저장.
4. **공개본 조회**: 소비자 화면은 게시본이 존재하면 해당 정보를 표시하고, 초기에는 명확히 시연 정보로 안내.
5. **게시본 복구**: 관리자 화면에서 서버 공개본을 브라우저 초안으로 다시 가져오는 기능.
6. **접근 권한**: `supabase/001_publication.sql`에서 등록된 관리자만 게시할 수 있도록 RLS 정책 작성. DB 설치 전에는 게시 비활성화.

## 필수 준비

자세한 순서는 **[`docs/ITDA_V4_PUBLISHING_GUIDE.md`](docs/ITDA_V4_PUBLISHING_GUIDE.md)** 에 정리했습니다. SQL은 `supabase/001_publication.sql`, 환경변수 예시는 `.env.example`을 참고하세요.

**주의:** Supabase 계정·프로젝트·환경변수는 실제로 연결된 상태가 아닙니다. ZIP을 배포하는 것만으로는 서버 게시가 작동하지 않습니다. `service_role`, `sb_secret_*`, 비밀번호는 소스코드나 Vite 환경변수에 넣지 마세요.

**아직 미구현:** 실제 사진·지도 배경 이미지의 서버 업로드 및 공개, 공개 편집 화면 접근 차단, 점주별 인증, 공공데이터 API 자동 업데이트, AI 자동 점포 인식, 360도 거리뷰. `/owner`의 마케팅 기능은 예시 기반 시연이며 공개 게시 DB와 자동 연동되지 않습니다.

`/editor`의 사진 포함 백업과 `/catalog`의 점포 JSON 백업을 모두 활용해 로컬 데이터 유실에 대비하세요. 실제 영업 정보가 아닌 가상 점포는 외부 공개 전에 반드시 정리해야 합니다.
