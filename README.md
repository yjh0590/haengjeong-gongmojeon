# 맛&멋 AI Street — 지도 중심 개선 버전

Vite + React + TypeScript. 소비자용 거리 탐색과 기존 점주용 콘텐츠 승인 화면을 포함한 **시연용 프로토타입**입니다.

## 실행·배포

```bash
npm ci
npm run dev
npm run build
```

- `/` 소비자용: 구역 안내도, 점포 검색·필터, 촬영 지점별 거리 사진, 즐겨찾기, 등록된 이벤트
- `/owner` 기존 점주용: 콘텐츠 제안·승인 (기존 코드 유지)
- `/street-editor` 새 도구: 촬영된 사진에서 점포 영역을 다각형으로 지정하고 JSON 내보내기/가져오기
- `vercel.json` SPA 경로 새로고침 대응

## 이번 변경

1. 지나치게 큰 히어로를 축소하고 **지도와 거리 사진을 같은 높이로 먼저 노출**.
2. 기존 **비활성 메뉴**를 ‘거리 탐색’과 지도 내 ‘오늘의 발견’으로 연결.
3. 미니맵을 **클릭 가능한 시범 구역 안내도**로 변경: 1~4 촬영 지점 직접 이동, 가게 누르면 관련 지점 선택.
4. 기존에 연결이 없던 **1번 지점 → 2번 지점 이동 링크** 복구.
5. 검색을 현재 촬영 지점 한정이 아닌 **전체 시연 점포 기준**으로 수정. 맛/멋/이벤트 필터와 ‘저장한 가게’ 추가.
6. 즐겨찾기를 `localStorage`에 저장, 점주용 승인 문구의 소비자 노출은 기존 방식 유지.
7. **맛(파랑) / 멋(갈색) / 이벤트(노랑)** 시각적 구분.
8. `src/data/facadeAnnotations.ts`와 `/street-editor`를 추가하여 사진 속 점포 다각형 등록 가능. 소비자 화면은 실제 등록된 영역만 표시.
9. 현재 점포 정보가 예시 데이터이므로 **외부 길찾기 버튼을 허위 목적지로 연결하지 않도록** 안내도 위치 보기로 변경.
10. 촬영하지 않은 방향은 ‘촬영 준비’로 표시. 실제 일반 사진을 360°로 표현하지 않음.

## 거리 사진 추가

1. `public/street/point2-forward.jpg` 등 사진을 추가.
2. `src/data/streetNodes.ts`의 해당 지점 `views`에 `/street/point2-forward.jpg` 경로 입력.
3. 필요한 경우 `connections`에 지점 간 이동 설정.
4. `/street-editor`에서 사진의 가게 외관을 따라 꼭짓점을 클릭하여 저장. JSON 내보내기 가능.

**주의:** `/street-editor` 저장 데이터는 방문자 **각자 브라우저의 localStorage**에만 반영됩니다. 여러 사용자에게 동일한 영역을 보여주려면 `src/data/facadeAnnotations.ts`의 `builtInFacades` 상수로 JSON을 반영하거나 서버 DB를 추가해야 합니다. 이 도구는 로그인 없이 노출되는 시연 환경이므로 운영용 관리자로 사용하지 마세요.

## 한계 및 향후 작업

- **실제 지도 아님:** 현재 구역도 및 A~F 점포는 **실측 좌표 없는 예시**입니다. 실제 주소·건물 동/층/호수와 검증된 지도 좌표를 확보해야 위치 오류를 바로잡고 길찾기를 연동할 수 있습니다.
- **360° 아님:** `point1`에 2048×1536 일반 사진 2장만 제공됩니다. 완전한 360° 파노라마와 로드뷰식 연속 이동에는 별도의 촬영·스티칭·노드 작업이 필요합니다.
- **AI 추천 예시:** 현재 추천 점수는 정적 샘플 값이고 실시간 AI 추론이 아닙니다. AI 점포 분할과 챗봇은 미구현입니다.
- **실시간 데이터 아님:** 점주 승인 및 즐겨찾기는 브라우저에만 저장됩니다. 점주/소비자 간 실시간 공유, 공공데이터 API를 통한 신규·폐업 탐지, 관리자 승인 워크플로는 아직 구현되지 않았습니다.
- **이벤트 검증 필요:** 오늘의 발견은 등록된 행사 텍스트를 표시하며 실제로 오늘 진행 중인지 검증하지 않습니다.
- **지역 확장:** 새 구역마다 실제 좌표와 사진, 점포 데이터를 수집·관리해야 합니다.
