# Guidebook font

Gowun Dodum (고운돋움), distributed under the SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/gowundodum

GowunDodum-Guide.ttf is the text subset returned by the official Google Fonts CSS API, requested with the unique characters in src/data/guidebooks.ts, src/components/GuideLibrary.tsx and src/pages/Landing.tsx. It is hosted locally, so opening the guide does not contact a font service. New guide text may need the subset refreshed; unsupported characters use the system fallback.

The original license is preserved as GowunDodum-OFL.txt. The font is scoped to the guidebook and its widget.
